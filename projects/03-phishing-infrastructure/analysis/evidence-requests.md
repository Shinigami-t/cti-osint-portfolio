# Evidence Requests — Operation Glass Finch

## Request 1: Original email and full headers

**Purpose:** Examine message routing, sender information, and authentication results.

**Key fields:** Received, Return-Path, Authentication-Results, From, and Reply-To.

**Question:** Did the message pass through expected mail infrastructure, and do authentication results support the claimed sender identity?

## Request 2: Mail gateway logs

**Purpose:** Determine how the email entered the organization's mail environment and identify related messages.

**Question:** Was the message received from an external sender, and were similar messages delivered to other employees?

## Request 3: DNS and domain records

**Purpose:** Gather infrastructure context for the sender domain, where applicable.

**Records of interest:** MX, A, TXT, and relevant historical DNS records if available.

**Question:** What infrastructure is associated with the domain, and what can those records actually establish?

## Limitations

No original headers, mail logs, or DNS results are available in this fictional case. These are proposed evidence requests, not completed investigations. No conclusions should be attributed to records that have not been obtained.
