# Project 05 — OSINT Image Geolocation

**Analyst:** Shinigami-t  
**Date:** 28 October 2026  
**Status:** Investigation in progress

## Objective
Investigate a photograph using visual clues, image metadata, open-source research, and independent corroboration to determine its likely location.

## Case Overview
The target photograph contains a storefront and several environmental features that may help identify the location.

Initial observations include:
- A sign reading "FAILTE".
- A horse graphic and wording mentioning Kentucky.
- Nearby power lines and a car park.
- A small planted area with grass and pots.

Kentucky is a working hypothesis, not a confirmed result.

## Methodology
1. Preserve the target image.
2. Inspect available metadata with ExifTool.
3. Record visible clues without treating assumptions as facts.
4. Develop and test location hypotheses.
5. Corroborate candidate locations using independent sources.
6. Document evidence, limitations, and confidence.

## Important Limitation
The original source reportedly publishes location information. This is a practice investigation, not a fully blind geolocation exercise. The final assessment must distinguish independent findings from information obtained through external research.

## Current Conclusion
The exact location remains unconfirmed. Further source verification and scene comparison are required before a final conclusion can be made.
