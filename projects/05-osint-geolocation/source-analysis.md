# Source Analysis — Project 05

## Source S-01: Target Photograph
- File: blind-target.jpg
- Type: Image evidence
- Use: Visual inspection and metadata analysis
- Reliability: Primary evidence for features visible in the photograph.
- Limitation: The image's original source reportedly publishes location information, so it is not a blind challenge.

## Source S-02: Embedded Image Metadata
- Tool: ExifTool 13.50
- Type: Technical metadata extracted from the image
- Findings: Sony SLT-A57 camera information and an original timestamp of 21 October 2012.
- Reliability: Useful for describing the embedded metadata, but the timestamp and camera information do not establish geographic location.
- GPS: No GPS latitude or longitude fields appeared in the inspected output.

## Source S-03: Preliminary Business Research
- Type: External open-source research
- Lead: A possible Irish-themed shop in Lexington, Kentucky.
- Status: Unverified candidate.
- Limitation: The candidate must be compared with the target photograph before it can support a location conclusion.

## Source S-04: Analyst Visual Observations
- Type: Analyst-generated observations
- Findings reported: "FAILTE" sign, horse graphic, Kentucky wording, power lines, car park, and planted area.
- Reliability: Preliminary observations requiring visual confirmation where details are unclear.

## Source Evaluation Rules
- Prefer original and official sources for business identity and location.
- Record exact URLs and access dates when sources are verified.
- Distinguish direct observations from claims made by external sources.
- Seek independent corroboration before accepting a location.
- Do not treat multiple pages repeating the same original claim as independent confirmation.

## Current Assessment
The available information is sufficient to generate a candidate hypothesis, but not to confirm the exact location. The source URL, image licence, and candidate-scene comparison remain outstanding.
